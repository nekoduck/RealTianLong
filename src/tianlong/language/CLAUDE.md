# language/
> L2 | 父级: /CLAUDE.md

开放语义与文字表达。LLM 只做两件事：把玩家的自由文本解析为结构化意图、把已经成立的事件按玩家可见范围写成文字。它永远不裁定事实；任何模型输出都要回到 kernel 结算。文字 ≠ 事实：模型成功返回的非空文字也要先过 render 的确定性语义闸门，命中即回退模板——提示词只是请求，闸门才是验收。

成员清单
templates.py: 确定性文本层（无 LLM），render_fact/render_event/render_experience/render_percept 角色视角措辞（名称表即观察者的实体草图，按种类说"在桌上/在身上"）+ 失败原因/研读进境（未贯通者明说未贯通，免得润色时被夸成学成）/武侠状态措辞 + 没有原话的言语按言语行为写成动作（SOCIAL_VERBS：“向钟灵打了个招呼”，耳语才是“低声说了些什么”）+ 自己移动只写“来到”（步态留给原话），旁人来到眼前写出他从哪道（认得的）门过来——“钟灵经断崖来到剑湖畔”，旁人推门未果只写“走向那道门”；原著路线的叩拜（带服软的查看）写成“伏地磕头，顺势细看”；出手被挡只说“被对方化解了”（弱者靠貂、靠运气避过强者的一掌，交给叙述者写得合情理） + 事件后果（伤毒被制、学成、暗道与藏匿之物）+ consequences() 事件的看得见的后果（先声复用；翻出的藏匿之物按藏处归成一句“发现蒲团上藏着……、……”，familiar——此前已知下落的——只说“……仍在蒲团上”）+ 所见清单按所在处归拢（“干光豪、葛光佩都在剑湖宫大殿；长剑在兵器架上”，每条“在”的事实照旧都在），看得见的通道也在所见里（“小门连着后山”，不说能不能走）；memory、speaker、narrator 共用
llm.py: LLMClient 协议（generate + stream）+ GeminiClient（REST，密钥只从环境变量读、只走请求头、异常信息里抹掉；每线程一条 HTTPS 长连接、经代理走 CONNECT 隧道；只有闲置长连接被对端关掉才重连一次，超时与新连接上的挂断绝不重发，出错或没读完的连接一律关掉；显式思考档位，接口不认就逐级降档（→ low → thinkingBudget 0 → 去掉），看所发的请求体；SSE 流式，流内错误、提示词被拒、结束原因不是 STOP（SAFETY/RECITATION/MAX_TOKENS/OTHER）或没有结束标记都在交出已收到的文字之后抛；generate 对来得快的 429/500/503 等 0.2 秒重试一次；型号不可用退回 -latest 别名；每次调用记首字与总耗时 CallStat）+ CachedLLM 磁盘缓存（只在 TIANLONG_LLM_CACHE=1 时启用，原子写入，坏条目算没命中）+ ScriptedLLM 离线脚本回放（可模拟延迟与流式）+ llm_from_env()（叙述模型，默认 gemini-3.8-flash、思考 low；默认包一层 HedgedLLM，替补与 fast_llm_from_env 同样装配、GEMINI_HEDGE_AFTER 秒不出字即上场（默认 2.5，0 不对冲，开缓存不对冲））/ fast_llm_from_env()（解释用快模型，默认 flash-lite、思考 minimal）；任何失败只抛 LLMUnavailable，调用方必须回退模板
lead.py: lead_line() 先声：玩家本回合自己的行动（SELF 感知）写成确定的一两句人话——到了哪、拿到没有、说了什么、失败说明原因、动手写出后果；只说玩家自己，旁人的言行留给声音模型，干等不抢先，伏地叩拜写成磕头而不是“四下打量”；原话与姿态里的话缺句末标点只补句号、不动字；措辞按 (tick, 操作, 对象) 派生的种子在几种说法里确定轮换。结算一完成就能交给玩家，首字不等模型；restates() 判定模型的一句是不是只在复述先声（主语是“你”、同一动作的动词 + 同一对象或原话再现；还写到别的人、写得很长、查看此地而不点地名的都不算）；先声同样带 familiar，已知下落的东西只说“仍在”
hedge.py: HedgedLLM 首字对冲（包在任何 LLMClient 外、自己也是 LLMClient）：主模型 after 秒内没吐出第一段字或提前出错，就把同一请求并发给更快的备用模型，先出字的一路讲完整段、另一路作废（下一段字到达时关连接，不交付任何文字），两路都失败才抛 LLMUnavailable；读流在常驻线程池里，GeminiClient 的每线程长连接跨回合复用；generate 不对冲、只在主模型失败时交给备用；hedged/switched 计数供评测
speaker.py: Speaker 协议 + TemplateSpeaker + LLMSpeaker，把结构化言语行动说成符合人设的一句话；事实以命题为准，原话只是修辞；LLM 润色须过对白闸门（只许点名说话者、听者、话题主语与宾语——名或别称，不许多出意图里没有的承诺与状态，必须提到话题主语——本人可称“我”、听者可称“你”），否则回退模板；拒绝全集是会话交来的场景全部实体名与别称加说话者认识的名字，说话者没听说过的真实实体同样不许点名：原话随意图落库、被听者记住，再被叙述者当作有出处的名字照搬，分歧一旦提交就撤不回
command.py: 语态分析，analyze() 在选操作之前判定这句话是不是“玩家此刻要做的一件事”——否定作用域（跨情态词与介词短语回溯，双重否定判为不确定）、条件/计划/斟酌、转述（他人作主语或过去时标记）、引语、复合分句（言语动词之后的内容不算行动）、可行性疑问；言语行为词 SOCIAL_WORDS（打招呼/赔罪/救命……→ Social，归 TELL；“聊聊天/说会儿话”整词算，不剩下一个“天”当原话）与姿态词 GESTURE_WORDS（打量/坐下/拱手/发呆/出神/闭目养神……，归 WAIT；张望/望了望/看了看/瞧瞧是四下看看，归 INSPECT）也是行动词，盖住里面的单字（“打招呼”不是打、“救命”不是救、“坐下”不是下），同样受否定与条件约束；action_hits() 给出去掉引语与被长词覆盖之后的命中；ParsedCommand 保留语态、主体、否定操作、条件与分句跨度；clarify() 给出不推进时间的追问
parser.py: Parsed（含 MoveKind：行动/说话/姿态/问主持人/元指令/听不懂，多步行动的 followups，问主持人的原话 question）+ rule_parse 语态闸门 → 规则解析（只收单一、肯定、即时的指令，按优先级尝试所有命中关键词的操作，都不成时给最具体的场内追问；结果带类别：言语=SAY、姿态=GESTURE）+ IntentParser（规则失败或非即时语态才调 LLM，JSON Schema 约束，必须声明 mode 与 actor，只有 immediate+player 被接受，且压不过规则看见的否定；LLM 失败或回复不成形（不是对象、未知操作/方式、字段类型不对）绝不回退到未经语态确认的候选）；可引用实体只来自玩家认知图（场景别称只对已认识的实体生效）；规则层修掉的误判：打招呼/打量不是动手、看人是打量而明说“搜”才搜身、磕头只在玩家以为此地有神像/蒲团一类可拜的陈设时才是原著路线的伏地细看（其余——向人、当众、兵器架前——是服软姿态）、大喊救命/用易经挡脸不是施用、点了不认识的名字不默认手里那件、言语只有说清“谁在哪/在哪”才带命题，原话只引说出口的那句（speech_line；听者只是定语——“拍拍钟灵的肩膀”——就没有原话），没有听者的言语行为是当众姿态；先叫人再说话（“钟灵，……”“喂，龚光杰，看招！”——句首的人名紧跟逗号或冒号，此人在眼前）整句是说给他的原话（带上客套的言语行为），后面还有别的动作（“马五德，我们去后院吧”）先按动作解、解不出（“钟灵，把解药给我”）才当话说；掏出/拔出之后的名字以出招动词为界（“拔出倚天剑刺向他”取“倚天剑”）；姿态过 pose.witness()，夹带的拿取/研读落空就照实说落空、不被姿态吞掉；言语在原话之外（unsaid()）声称掏出/拔出的同样要真在手里；normalize() 让 MOVE 绑定玩家知道的路（“朝门走”= 经这扇门去对面，“去某地”= 经认为连通的门，点名的门不通就换一条，目的地是脚下不算移动，不知道路就追问；查看一扇门或一件东西——“往崖下望了望”“看看那把剑”——内核不收，改成在此地四下细看），normalize()/exits()/leave_here() 可指定出发地（多步计划从上一步的终点算起），leave_here() 只有一条出路才替人走、leaving() 判断说没说要离开；wield_problem() 拦“掏出/拔出”不在身上的东西（“拿出勇气/亮出身份”是说法不算）；等待可带时长（只认紧挨“分”的十进制数字，“²/①”不崩）或“等到天黑”；规则机件（mentions/held_items/exits/leaving/invalid/manner_of/speech_manner/wait_length/unwrap_line/unsaid/pose_of）供解释器复用
interpret.py: 主持层解释器 Interpreter（设计 §4.1），interpret(text, me, recent) → Parsed：GM:/OOC: 前缀与明显的场外问题 → ASK_GM，/hint /recap /beliefs → META（都不调模型、不推进时间）；高精度规则快路径只收整句命令（实体换成占位符后整句匹配白名单，再交 rule_parse 定角色，单字关键词从不单独成立，问号结尾的非问话命令交给模型判语态，磕头按此地有没有可拜的陈设走细看或服软姿态，亚毫秒、0 次模型调用）；其余一次快模型 generate（JSON Schema、max_tokens 300、中文系统提示），把任何第一人称输入归为 act（1~3 个内核步骤）/ say（听者 + 去掉包装的原话 + 言语行为 + 可选的“谁在哪”命题）/ gesture（不带主语的姿态）/ ask_gm / unclear，并声明语态与主体；逐项校验——实体须是玩家认识的且种类对、MOVE 经 normalize 且多步计划从上一步的终点算路（目的地是脚下时只有说了“离开/溜出”才替人挑出路，否则“你已经在……了”）、要在手里的须在（计划里先拿起的也算；言语只查原话之外的那截）、第一个不成立的步骤截断计划、一步不成就给场内说法不推进（编造前提的防线，不回显模型编的 id）；原话只收玩家打出来的字（模型的 line 不是原文的一段就改由规则的 speech_line 从原文里截，截不出就只有言语行为），命题的主语与处所须原文点名，姿态过 pose.witness()；回显只用玩家写过的名字：missing 不在原文里就用不点名的说法（冲着认识的人动手时缺的若是功夫——“点了他的穴道”“用六脉神剑点倒他”——说“你并不会……”，缺的若是兵刃——“倚天剑”——仍说“你身上并没有……”，不是“不知道说的是谁”），reply 点了玩家不认识的名字（场景别称、会话交来的名字全集 universe）或带 id 就换成固定追问；明确的假设（如果/万一/等……就）与别人作主语的转述，模型说“即时”也不替玩家动手或摆姿态；提示词只含玩家认识的实体（点名、此地与在场、出路优先，至多 40 个）、身上的东西、会的武功与最近两段正文；没有模型时退回 IntentParser，模型失败或回复不成形只退回规则解析、绝不再调一次模型
narrator.py: Narrator 主持人之声，输入只有玩家本回合的感知与会话交来的 SceneBrief（台词、最近正文、玩家原话、钩子、前后照应），台词本身算出处，前后照应（身体状况、意外与变化、眼前的地点与人、此地叫得出名字的东西、说话者近来的经历）同样算出处、其中的状态说出来不算升级；提示词写明玩家的身体状况（别写得像没事人，也别每回合都写疼：只在吃力或刚受伤时带一笔）、身边的人的伤势、玩家干等时眼前可做的事（hooks，只把目光引过去）、等待仍在同一个时辰里就说过了多久（“不觉过了两三刻工夫”）而不说“到了某时”、玩家的话没人接（别替他编答案，写出他没顾上回答的样子）、出乎他意料之处（写出觉察，不替谁解释）、收幕时收在余韵上不再抛选择；回话先接住玩家的话头（可据所知来历回答“他是什么来头”，问起怎么来的就照近来的经历答），谈资只给没说过的、提也只挑一条，闲话只可说谈资、他自己近来的经历与眼前看得见的事，没有回应玩家的话不许写成接玩家的话头；无事发生时有模型就写眼前的光景与身边的人，没有模型才是“时间悄悄过去”；familiar 里的东西再翻出来只说“仍在”；先声（lead_line，照样过闸门）默认迟到才上场：模型 LEAD_AFTER（1.5）秒还没交付一句就顶上、自成一段，模型不知道它、照常铺陈这一步（悬念留给模型快的回合）；lead_after=0 立即交付并告诉模型开头已写好、清单不再列玩家自己的行动；先声之后模型开头两句里复述它的（三字片段重合过半，立即模式另加 restates()）悄悄略过、夹带错的照样丢句，收尾补模板时不再重复先声讲过的行，而别的必讲之事讲到没有只看模型自己交付的正文（先声点过的名字不替别的事作证）；有台词时引语里的名字与状态词交给台词闸门按说话者查（check 的 quoted），叙述者自己的口吻照旧只许点名清单里的；安静的回合模型又没交出话来，照旧是“时间悄悄过去”；读流在常驻线程里边读边计时；模板先写成事实清单（fact_lines 由 render 提供、此处再导出；自称改为“你”，移动/查看后附所见，去重），清单里听见的 NPC 言语换成 render_voice() 的带言语行为台词（“龚光杰冷笑着向你叫阵：……”，只看见的耳语照旧，同一说话者原话相同的优先对应；闲话只写言语行为，措辞按语义输入确定轮换）；narrate_scene() 有模型时流式生成（无 stream 则 generate），逐句对“已交付 + 本句”跑 check()、逐句传闻 restated_hearsay()、人事闸门 check_deeds() 与台词闸门 check_quotes()、再查钟点数字（含“19点20分”“七点二十分”，“一点半点”不算），通过即经 on_text 交付、违规即丢弃并记下，交付满 MAX_CHARS 字即停止读流；系统提示要结尾停在钩子上、但不替玩家列选项、不用“你是……还是……？”；收尾传闻归属整段查，台词没说出口（没有原话、说法、也不是回应玩家的闲话漏写了不补）、玩家自己的行动与后果/冲着玩家来的事/听见的话一个参与者都没提的补上模板行（gated_fallback +
