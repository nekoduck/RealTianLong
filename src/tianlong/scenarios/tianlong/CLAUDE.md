# scenarios/tianlong/
> L2 | 父级: /src/tianlong/scenarios/CLAUDE.md

天龙八部世界，以金庸《天龙八部》世纪新修版为蓝本，按剧情区域逐幕构建。每一幕只摆好世界、角色目标与各自所知，不写剧本：原著情节应当能由规则内核与角色认知涌现出来，而玩家可以走向原著之外。文字素材为原创转述，只描写看得见的样子，不预告剧情、不泄露他人心思。

第一幕·无量山：比剑方罢的剑湖宫（开场停在龚光杰将要发作的一刻）、后山禁地、只能下不能上的断崖、崖底剑湖与月夜显影的无量玉璧、玉璧旁夜里才看得见的石缝、琅嬛福地里的玉像、绣着字的蒲团与两卷帛书（北冥神功 → 吸功、凌波微步 → 闪避）、只能出不能进的山腹隧道、围山的神农帮；抵达澜沧江畔即第一幕终。

成员清单
wuliang.py: build_wuliang()，10 处地点、10 条通道（含单向断崖与隧道、夜现暗门）、10 个角色的身手与目标（龚光杰寻衅至段誉受伤、钟灵护着段誉、干葛二人 19:20 私奔投神农帮并灭口撞见的落单者、神农帮守营守道）；盟友按门户划分（EAST / WEST / SHENNONG / LOVERS 名册：东宗护东宗、西宗护西宗、两位掌门一致对外、私奔的一对只认彼此与神农帮、神农帮把来投的人当自己人）；每个角色的腔调 voice / 谈资 knows（按“；”分条，只点名本人开场就认识的实体，不含秘密）/ 公开来历 intro（别人被问到“他是什么来头”时的依据）/ 话多 chatty / 脾气 temper；段誉的目标（ESCAPE 澜沧江畔 + DEFEND 钟灵，只驱动提示）；各自所知（本门知道剑湖畔有无量玉璧、帮主与帮众知道彼此守在哪）；结局 ENDINGS（澜沧江畔；山道那头没有“山下”，不设下山结局）；SECRETS 秘密的说法（私奔、投神农帮……），只交给叙述闸门拦剧透
lore.py: SETTING 世界前提（收在开场对峙的钩子上）、STYLE 文风、LORE 外观描写（"id@night" 为月下变体；"门@pass" 是穿过这道门的经过——攀着藤萝落下断崖；蒲团绣字只是外观）、ALIASES 别称（“剑湖宫”记在大殿名下，免得被截成剑湖畔的“剑湖”）、COMMON_WORDS 别称里的普通名词（石壁、垫子）、HINTS 不剧透的输入示例、GUIDE 由浅入深只点方向的逐级提示（七条，末条落在琅嬛福地；只说方向，不替玩家“听说”没人告诉过他的事）与 GUIDE_AT 各处的起点、EPILOGUE_RIVER 终章基调
__init__.py: 包入口
