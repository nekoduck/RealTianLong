# runtime/
> L2 | 父级: /CLAUDE.md

装配层。把内核、认知、存储、记忆、智能体与语言串成可玩的会话。角色决策可以并行，事实提交只经 WorldAuthority 串行发生。重试与读档不让世界多走一步：意图幂等（意图 ID）之上还有请求幂等（TurnEnvelope），会话运行态随提交落库、读档原样恢复，存档版本不符即拒绝。

成员清单
choice_model.py: ChoiceSpec 与冻结 Parsed 的显式 JSON 编解码；文案与执行语义分开，动作 ID 取自路线、方式、话题、时长与计划
choice_builder.py: REQUEST_ITEM → 等待真实交付 → USE 只按已知库存与伤毒生成； 从玩家认知与自己的目标识别威胁、待回答、伤毒、修习和探索；先覆盖当前问题，再在 24 项预算内枚举三项组合，按具体打算衡量差异，路线与方式不丢，同分按语义 ID 排序；不读取世界真相或 NPC 私密目标
choice_history.py: 有界持久尝试记录只来自玩家 SELF 感知；失败按相关知识摘要阻挡，progress 放行，mastered 停止；目击放置线索跨越 12 条经历缓冲保留，已搜处因新线索或昼夜变化恢复；随世界首 tick 同事务提交
choice_service.py: 按世界版本发布并读取持久化决策，浏览器只得到选项 ID 与文案；旧请求重放先于菜单过期检查，首 tick 原子消费菜单
authority.py: WorldAuthority 每个世界实例唯一的权威写入器，settle() = 幂等检查 → 内核裁定 → 认知折叠 → 经历提炼 → annotate 附注（调用方看到未落库的结算后给出请求进度与会话运行态）→ 原子提交；found() 由场景建世界（信任度与自己人取自角色设定，写进各自心里）并记下存档版本
session.py: GameSession 装配中心与主持层的回合循环（存储里已有该世界则先过存档版本闸门再读档接续，恢复调度标记、已描写实体、最近三段正文、提示进度与选项尝试记录，并从经历记录重建向量索引；落幕与否由世界真相推出），turn(text, request_id, on_text) 一回合 = 解释玩家输入（_parse：有主持层解释器就用 interpret(text, me, recent)，否则规则解析器 + 元指令/“GM：”前缀兜底；同时在后台线程按同一版本预算首 tick 的 NPC 决策——首 tick 时版本未变才用，否则或本回合不推进就作废，与顺序执行逐项相同；元指令与“GM：”前缀一眼认得，不白算这一份）→ 按 MoveKind 推进：ACT 的 1~3 步计划逐 tick 执行（第 i 个 tick 走第 i 步，由已提交的 tick 数推出，失败即截短计划、随提交落库），SAY/GESTURE 或冲着（玩家以为）在场之人的动手/递物/施用/说话再加一个反应 tick，普通等待按时长、只被要紧的事打断（当面动手、对同伴——自己人与 DEFEND 目标——动手都算；计划与反应 tick 从不截短），ASK_GM（只用玩家自己的认知、目标、到下一条为止的提示与最近正文问声音模型，限两三句、流式边生成边逐句过名字闸门交付，点了玩家不认识的名字那句不交付且不再读流，一句未交出即回退模板）、META（/hint 逐级提示、/recap、/beliefs）与追问（模型写的场内说法同样过名字闸门，玩家自己说出的名字不算，拦下即换成不带名字的追问）不推进时间也不落库，带 request_id 的只记在本进程（最近 64 个）、重试原样返回（提示不多翻、模型不再问）、异内容抛 RequestConflict → 调度器分出需决策者、其余例行等待 → 权威结算 → outbox 同步索引 → 只用落库的请求进度与此刻各人认知拼出 SceneBrief，叙述者有 narrate_scene 就流式交付（经 on_text，记下首字耗时），否则 narrate_rendered → 抵达结局地点即落幕（之后的回合回“第一幕已终”），epilogue() 以场景给的结局标题开头（“第一幕终 · 澜沧江畔”），先收束（模型只取玩家亲历、过名字闸门）再附明确标注的真相揭晓；NPC 决策图一律用 TemplateSpeaker（台词由主持人之声写出，LLMSpeaker 保留但会话不用），向量回忆只为声明 reads_memories 的策略而跑；记录已描写过的实体只在初见时描写；每个 NPC 的长期记忆摘要从权威经历记录增量汇总（派生数据，读档后重建）（水位含边界、按记录 ID 去重：同一 tick 分两次提交写下的经历也不漏，与读档后从全部记录重建逐项相同）；每个 tick 的请求进度（含多步计划 followups 与反应 tick）与会话运行态先在副本上推进、随世界同一事务落库，提交成功才替换内存；最近正文在叙述之后更新、随下一次提交落库；同 ID 同内容返回既有结果、异内容抛 RequestConflict，叙述先写者为准（正常完成的一方同样返回并记住落库的那一段），提交后崩溃的重试只按已持久化的感知重写文字，多 tick 请求中途崩溃只走剩下的 tick，request_id=None 每次都推进；请求绑定由存储在提交内检查，并发的重复投递每个 tick 只有一次能提交，被越过的一方即停（不多走 tick、会话运行态改回落库的那一份），以落库的请求为准返回，对方未走完时只给目前的文字、不落库；进度与世界版本两次读一致才判定“别人越过了它”；建档后尚无提交就读档，开场已描写的实体按开场规则补回；TurnReport 携带类别 kind、结局 ending、首字耗时 first_text_ms、分阶段耗时（interpret/npc_decide/settle/index/narrate）、叙述上下文 brief、真相、NPC 理由，另记文字侧结果 render（来源 + 闸门结论）与 replayed
gm.py: 主持层纯函数（只读传进来的认知、请求进度与事件日志）：gm_command() 元指令与“GM：”前缀，companions() 玩家的同伴 = 自己人 + DEFEND 目标（与 NPC 替谁出头同一口径），salient() 等待只被要紧的事打断（冲着我来的、我的处境变了、当面公开说话或有所指的姿态、当面动手（打的是谁都算）、有人对同伴动手、有人进出我所在之处；例行举动、远处响动、耳语不算），build_brief() 从玩家听见的 NPC 言语与看见的 NPC 姿态拼 VoiceLine（说法与可点名的名字取自说话者自己的认知、腔调谈资取自设定、冲着玩家且在他开口之后的话带上他的原话），self_view()/goal_text()/aside_prompt()/closing_prompt() 给声音模型的提示词只含玩家自己的认知与亲历，gated_stream() 场外回答逐句（同叙述者的分句器）连同已交付的过名字闸门、通过即经回调交付，一句不过即停且关掉流，中途断线保留已交付的，leaked()/leaks() 名字闸门（玩家亲口说出的那几个字不算泄露），reveal() 终章的真相揭晓（每个 NPC 你以为的 vs 实际的下落与伤/毒/被制，玩家不在场时的动手、偷盗、施用与潜逃者的去向）
versions.py: 存档版本闸门，current_versions() = 存档格式 + KERNEL_VERSION + 属性规格指纹 ATTRS_VERSION（core/attributes 唯一定义，跨进程稳定）+ GOALS_VERSION；check_save() 不一致即抛 IncompatibleSave，allow_migration=True 才接续且不改写、不补写旧档
cli.py: 终端前端 main()，叙述经 on_text 逐句流式打印；开场只讲玩家所见并附上不剧透的输入示例（Scenario.hints）；/hint /recap /beliefs 与“GM：”场外提问交给会话（不推进时间），/debug 看真相、NPC 理由与分阶段耗时（含首字耗时），两种视角刻意分开；落幕即打印终章与真相揭晓并退出（读到已落幕的存档同样）；--llm auto 有密钥即启用：叙述用 llm_from_env()、解释用 fast_llm_from_env()，interpreter_for() 以受保护的导入接入主持层解释器（模块未并入时退回规则解析）；--world 选世界（默认天龙八部·无量山）；--store neo4j --save 名称 实现跨进程存档（版本不符一句话说明并退出，--allow-migration 显式接续）；--predictor gnn / --policy learned 经 learning/bundle 加载部署包（--artifacts 指向含 bundle.json 的目录：逐项核对训练时的语义版本与文件哈希，策略配套的预测器随包决定），缺包、被改动或不兼容时一句话提示并退出；load_dotenv() 读取 .env 只补缺不覆盖
web.py: --allow-migration 显式接续旧规则存档； 网页前端 WebGame 串行回合、缓存开场/终章、保存最近 200 回合；WebSessions 按随机 HttpOnly Cookie 隔离每个浏览器，用 SQLite 存档并保存最新会话运行态，缓存有界且只淘汰没有在途 HTTP 请求的会话，服务重启与缓存淘汰后可恢复。POST /api/turn 接入 request_id 幂等；game_id 拦截重开前的旧标签页请求；断线只停止传送、不打断结算与记录；SSE/JSON 双传输（代理不支持 SSE 可用 JSON）；非法 JSON、长度、类型与跨站 Origin 受控拒绝，/healthz 不创建游戏。main 支持 PORT / TIANLONG_DATA_DIR / --data-dir / --transport；网页只收到玩家认知中的文字、建议与结局，不收到 NPC 理由或调试真相
suggest.py: suggestions(me) 是旧调用方的文案兼容入口，转交 choice_builder；网页冻结完整动作并以 ID 执行，不把展示文字送回解释器
webpage.py: PAGE 内联 HTML，宣纸色调、台词着色、手机/深色模式；刷新从服务端恢复对话。每回合生成 UUID 并记录未完成请求，网络中断自动重试同一编号且提供手动重试，刷新继续待完成回合；忙碌与待重试时禁用其他行动，重开后清除待重试记录，终章后仍可查看回顾与认知；正文以 done 中持久化的叙述为准，支持 SSE 和 JSON 响应
__init__.py: 包入口
