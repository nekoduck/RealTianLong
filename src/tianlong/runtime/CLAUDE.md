# runtime/
> L2 | 父级: /CLAUDE.md

装配层。把内核、认知、存储、记忆、智能体与语言串成可玩的会话。角色决策可以并行，事实提交只经 WorldAuthority 串行发生。重试与读档不让世界多走一步：意图幂等（意图 ID）之上还有请求幂等（TurnEnvelope），会话运行态随提交落库、读档原样恢复，存档版本不符即拒绝。

成员清单
authority.py: WorldAuthority 每个世界实例唯一的权威写入器，settle() = 幂等检查 → 内核裁定 → 认知折叠 → 经历提炼 → annotate 附注（调用方看到未落库的结算后给出请求进度与会话运行态）→ 原子提交；found() 由场景建世界（信任度与自己人取自角色设定，写进各自心里）并记下存档版本
session.py: GameSession 装配中心与主持层的回合循环（存储里已有该世界则先过存档版本闸门再读档接续，恢复调度标记、已描写实体、最近三段正文、提示进度、谈资账本与驱力标记，并从经历记录重建向量索引；落幕与否由世界真相推出），turn(text, request_id, on_text) 一回合 = 解释玩家输入（_parse：有主持层解释器就用 interpret(text, me, recent)，否则规则解析器 + 元指令/“GM：”前缀兜底；同时在后台线程按同一版本预算首 tick 的 NPC 决策——首 tick 时版本未变才用，否则或本回合不推进就作废，与顺序执行逐项相同；元指令与“GM：”前缀一眼认得，不白算这一份）→ 按 MoveKind 推进：ACT 的 1~3 步计划逐 tick 执行（第 i 个 tick 走第 i 步，由已提交的 tick 数推出，失败即截短计划、随提交落库），SAY/GESTURE 或冲着（玩家以为）在场之人的动手/递物/施用/说话再加一个反应 tick（同伴在身边时走开也加一个，让跟着你的人当场跟上），普通等待按时长、只被要紧的事打断（当面动手、对同伴——自己人与 DEFEND 目标——动手都算；计划与反应 tick 从不截短），ASK_GM（明说“GM：”才是场外、答话标“（场外）”，其余问话是故事里的自问、用故事口吻答且不标场外；提示只在场外或问到“怎么办、往哪走”时给；只用玩家自己的认知、目标、到下一条为止的提示与最近正文问声音模型，限两三句、流式边生成边逐句过名字闸门交付，点了玩家不认识的名字那句不交付且不再读流，一句未交出即回退模板）、META（/hint 逐级提示——身在何处决定至少从第几条说起（Scenario.guide_at），场外问答同样只给起点之后的提示、/recap、/beliefs）与追问（模型写的场内说法同样过名字闸门，玩家自己说出的名字不算，拦下即换成不带名字的追问）不推进时间也不落库，带 request_id 的只记在本进程（最近 64 个）、重试原样返回（提示不多翻、模型不再问）、异内容抛 RequestConflict → 调度器分出需决策者（驱力的时间窗打开也算，cast.wakes）、其余例行等待，有驱力的 NPC 经 cast.policy_for 套上 Driven → 权威结算 → outbox 同步索引 → 只用落库的请求进度与此刻各人认知拼出 SceneBrief（另拿本回合开始前玩家的认知做前后照应、此前已知下落的东西 familiar 再翻出来不算“发现”，抵达结局的那一回合 closing；提交后崩溃的重试补写叙述时没有 before，前后照应与 familiar 从缺、closing 不再判——已知的局限，只影响那一段措辞）；交给叙述闸门的别称用 Scenario.gate_aliases（去掉场景标注的普通名词：石洞里的“石壁”不是无量玉璧）；叙述模型开了磁盘缓存就不用迟到的先声（逐字复现），叙述者有 narrate_scene 就流式交付（经 on_text，记下首字耗时），否则 narrate_rendered → 抵达结局地点即落幕（之后的回合回“第一幕已终”），epilogue() 以场景给的结局标题开头（“第一幕终 · 澜沧江畔”），先收束（模型只取玩家亲历、过名字闸门）再附明确标注的真相揭晓；NPC 决策图一律用 TemplateSpeaker（台词由主持人之声写出，LLMSpeaker 保留但会话不用），向量回忆只为声明 reads_memories 的策略而跑；记录已描写过的实体只在初见时描写；每个 NPC 的长期记忆摘要从权威经历记录增量汇总（派生数据，读档后重建）（水位含边界、按记录 ID 去重：同一 tick 分两次提交写下的经历也不漏，与读档后从全部记录重建逐项相同）；每个 tick 的请求进度（含多步计划 followups 与反应 tick）与会话运行态（含 cast.advance_marks 推进的驱力标记）先在副本上推进、随世界同一事务落库，提交成功才替换内存；最近正文在叙述之后更新、随下一次提交落库；同 ID 同内容返回既有结果、异内容抛 RequestConflict，叙述先写者为准（正常完成的一方同样返回并记住落库的那一段），提交后崩溃的重试只按已持久化的感知重写文字，多 tick 请求中途崩溃只走剩下的 tick，request_id=None 每次都推进；请求绑定由存储在提交内检查，并发的重复投递每个 tick 只有一次能提交，被越过的一方即停（不多走 tick、会话运行态改回落库的那一份），以落库的请求为准返回，对方未走完时只给目前的文字、不落库；进度与世界版本两次读一致才判定“别人越过了它”；建档后尚无提交就读档，开场已描写的实体按开场规则补回；TurnReport 携带类别 kind、结局 ending、首字耗时 first_text_ms、分阶段耗时（interpret/npc_decide/settle/index/narrate）、叙述上下文 brief、真相、NPC 理由，另记文字侧结果 render（来源 + 闸门结论）与 replayed；不推进的回合与落幕分别由混入类 AsideMixin（aside.py）与 EndingMixin（endings.py）承担，GameSession 的公开接口不变，ENDED 照旧可从 session 导入
aside.py: AsideMixin 会话的不推进回合（从 session 原样迁出、行为不变）——_aside 分派（落幕之后回 ENDED、ASK_GM 场外问答、META 元指令、其余追问），带 request_id 的记在本进程（最近 ASIDE_KEEP=64 个）、_replay_aside 重试原样返回、异内容抛 RequestConflict；_clarify 模型写的追问过名字闸门（玩家自己说出的名字不算），拦下换成 clarify() 或 PARDON；_meta（/hint /recap /beliefs）；_next_hint / _floor 逐级提示从所在处（Scenario.guide_at）说起；_gm_aside 场外问答只用玩家自己的认知、目标（只在场外说）、到下一条为止的提示与最近正文，流式逐句过名字闸门、一句未交出即回退模板，“GM：”才标（场外）、故事里的自问只在问到怎么办/往哪走时给提示；_aside_pieces 有流式就流式、限两三句；TurnReport 在调用时从 session 取（模块顶层导入会成环）
endings.py: EndingMixin 会话的落幕（从 session 原样迁出、行为不变）——_ended 由世界真相推出（玩家身处结局地点），_reach_ending 落幕即定，epilogue() 终章 = 场景给全的结局标题 + _closing 收束（模型只取玩家亲历与最近正文、从不看真相，点了他不认识的名字或模型不可用即不用）+ gm.reveal 明确标作“真相”的揭晓
cast.py: 角色装配——policy_for() 场景给了驱力（或一次性提议）就把 Driven 套在策略外面（学得的策略也一样），否则原路径；wakes() 驱力条件里 Between 的起止落在上次决策与此刻之间即唤醒（不改 Scheduler）；advance_marks() 在副本上推进驱力标记，只记意图结算成功（Outcome.SUCCESS）的驱力（once/cooldown/Fired 据此判断），每条留最近 MARKS_KEEP 次；不依赖 LangGraph
continuity.py: 前后照应 continuity()——只拿玩家自己的认知比对“本回合之前以为的 vs 此刻看见的”，写成给叙述者的提醒：玩家自己的伤毒被制与刚好了的伤、你原以为某人被（玩家亲眼看见的某某）制在别处却在眼前见到了他（此时“被制”算说到的状态，叙述者写出“她明明被点了穴道”不算升级）、一路相随的同伴（companions）没跟来（被制住的同伴本就跟不来，不提）、身在何处身边有谁、此地叫得出名字的东西、通道与亲眼到过的地方（nearby；门那头没见过的地方不算，可点名、不进提示词；不在身边的同伴玩家惦记着的伤毒被制同样许说）、身边的人玩家以为的伤毒被制（hurt，写他们的举动别像没事人），并列出说到的状态（不算升级）与玩家身上确有的状态；本回合又走开的人不算“此刻在眼前”，从玩家走来的地方一路跟过来的同伴不算意外，原以为还在身边、环顾一看已不在的人说一声“不知何时已经不在这里了”，同一处从被制到能动说“此刻却已能动了”；提醒的措辞里不带新的状态（只有玩家此刻身上确有的状态算许可）；意外出现或刚走到眼前（半个时辰内亲眼看见他进来）的人开口时带上 lately()——到他开口那一刻为止、一路走到此地的那几步与冲着他来的动手（挨的打至多两件、优先留着，不被路程挤掉；短期经历有界，早先那一下与“是谁制住了谁”从各自的经历记录里找，挨过点穴而此刻能说能走就添一句“后来穴道自己解开了”；他对别人的动手、去过又离开的地方一概不给，免得替他交代隐情），只在他自己的引语里算出处；从不看世界真相
talk.py: 谈资账本——topics() 把谈资按“；”拆成条目，fresh() 给出还没说过的（至多两条），told() 判定一段正文说到了哪几条（三字片段过半；交给了叙述者、说话者也开了口的按人称归一后的两字片段三成认，换了说法也认得出）；会话在每段正文写成之后记账（谁说的都算，满堂的人都听见了），随会话运行态落库、读档恢复——NPC 不再每开口就把设定背一遍
gm.py: 主持层纯函数（只读传进来的认知、请求进度与事件日志）：gm_command() 元指令与“GM：”前缀，companions() 玩家的同伴 = 自己人 + DEFEND 目标（与 NPC 替谁出头同一口径），salient() 等待只被要紧的事打断（闲扯——没有命题的说笑与随口一句——不算；冲着我来的、我的处境变了、当面公开说话或有所指的姿态、当面动手（打的是谁都算）、有人对同伴动手、有人进出我所在之处；例行举动、远处响动、耳语不算），build_brief() 从玩家听见的 NPC 言语与看见的 NPC 姿态拼 VoiceLine（说法与可点名的名字取自说话者自己的认知、腔调取自设定、谈资只给谈资账本里还没说过的（至多两条；叫阵、讥讽、辱骂、威胁、喝令、回绝时不给）、玩家原话里问到的人附上说话者所知的公开来历 about、冲着玩家且在他开口、摆姿态或赔罪道谢之后的话带上玩家这一步作由头、刚来到眼前的人带上他近来的经历），并附上 continuity 的前后照应、是否收幕（closing）、玩家冲着谁说了话他却没接话（unanswered：别替他编答案）、普通等待被打断时的一句“你本想再等下去”、玩家干等且没人说话时的行动建议（hooks：把他的目光引过去，不替他决定）、当面动了手却没开口的 NPC 顺口喝的一声（act，一回合至多两个，可说可不说、漏写不补、没有模板），玩家的伤只在这一步吃力或伤势刚变时给、身边人的伤只给本回合有动静的人，self_view()/goal_text()/aside_prompt()/closing_prompt() 给声音模型的提示词只含玩家自己的认知与亲历（goal_text 按 PLAYER_GOALS 的玩家口吻，与评测对照组的世界圣经共用一张表），gated_stream() 场外回答逐句（同叙述者的分句器）连同已交付的过名字闸门、通过即经回调交付，一句不过即停且关掉流，中途断线保留已交付的，leaked()/leaks() 名字闸门（玩家亲口说出的那几个字不算泄露），reveal() 终章的真相揭晓（每个 NPC 你以为的 vs 实际的下落与伤/毒/被制，玩家不在场时的动手、偷盗、施用与潜逃者的去向）
versions.py: 存档版本闸门，current_versions() = 存档格式 + KERNEL_VERSION + 属性规格指纹 ATTRS_VERSION（core/attributes 唯一定义，跨进程稳定）+ GOALS_VERSION；check_save() 不一致即抛 IncompatibleSave，allow_migration=True 才接续且不改写、不补写旧档
cli.py: 终端前端 main()，叙述经 on_text 逐句流式打印；开场只讲玩家所见并附上不剧透的输入示例（Scenario.hints）；/hint /recap /beliefs 与“GM：”场外提问交给会话（不推进时间），/debug 看真相、NPC 理由与分阶段耗时（含首字耗时），两种视角刻意分开；落幕即打印终章与真相揭晓并退出（读到已落幕的存档同样）；--llm auto 有密钥即启用：叙述用 llm_from_env()、解释用 fast_llm_from_env()，interpreter_for() 以受保护的导入接入主持层解释器（模块未并入时退回规则解析）；--world 选世界（默认天龙八部·无量山）；--store neo4j --save 名称 实现跨进程存档（版本不符一句话说明并退出，--allow-migration 显式接续）；--predictor gnn / --policy learned 经 learning/bundle 加载部署包（--artifacts 指向含 bundle.json 的目录：逐项核对训练时的语义版本与文件哈希，策略配套的预测器随包决定），缺包、被改动或不兼容时一句话提示并退出；load_dotenv() 读取 .env 只补缺不覆盖
web.py: 网页前端 WebGame（一局游戏的线程安全外壳：同一时刻只结算一个回合；开场在后台先写好、只讲一次，终章只写一次，刷新页面原样再给、接着玩同一局）+ make_server()（标准库 ThreadingHTTPServer，零依赖）+ main()（python -m tianlong.runtime.web，--llm/--world/--seed/--host/--port）；POST /api/turn 以 SSE 逐句推送主持人之声（event: text），done 只带时辰、以为自己在哪、类别、是否推进、终章与行动建议——NPC 理由、真相、叙述上下文从不出这个进程；输入截到 MAX_INPUT 字，一回合出错只回 error 事件不拖垮服务
suggest.py: suggestions(me) 行动建议：只凭玩家自己的认知与候选集给出至多三句可直接照做的输入（每族一句：有人冲我来——狠话或动手——先赔罪与脱身，其次没看清的、没研读过的、没去过的），措辞落在解释器快路径的句式上，点了不必等模型；从不参考真相，所以不剧透；同一认知同一建议
webpage.py: PAGE 整页 HTML（样式与脚本内联、无外部依赖）：宣纸色调、NPC 台词单独着色、文字随 SSE 逐句浮现，输入框上方可点的行动建议，侧栏时辰/所在与提示/回顾/所知/明暗/重开，落幕展示终章卡片；深色模式与手机宽度皆可用；页面只呈现服务端给的文字，不做任何判断
